**Built from scratch. Ships with nothing else.**

Rathkit builds libraries and tools with no runtime dependencies. So far:

- **RTE**, a rich text editor with first-party wrappers for the major frameworks.
- **Pack**, a JavaScript and TypeScript bundler written in Rust with no dependencies, not
  even crates.

The code is open source under Apache-2.0. RTE also has paid options for larger teams.

**Status: pre-alpha.** Nothing is published yet, and the APIs will change.
